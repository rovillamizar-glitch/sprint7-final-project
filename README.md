# Proyecto Final Sprint 7 - ConnectaTel

## Descripción

En este proyecto se realizó un análisis de datos de una empresa de telecomunicaciones llamada ConnectaTel.

Se trabajó con información de usuarios, planes y consumo para identificar patrones de comportamiento, detectar problemas de calidad de datos y segmentar a los clientes.

## Objetivos

- Explorar los datos.
- Limpiar valores nulos y datos inválidos.
- Detectar outliers.
- Analizar el comportamiento de los clientes.
- Crear segmentos por edad y nivel de uso.
- Proponer recomendaciones para el negocio.

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
